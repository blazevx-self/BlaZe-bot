# BlaZe — Telegram RPG-бот

Многопользовательский RPG-бот для Telegram во вселенной «Токийского гуля»:
игровая экономика, прокачка персонажа, мини-игры, модерация групп и AI-собеседник.
Работает в продакшене на собственном VPS.

Вдохновлён ботом @chestor — механики переосмыслены и написаны с нуля.

## О проекте

- **~280 Python-модулей**, слоистая архитектура с Dependency Injection
- **PostgreSQL + Alembic** — схема БД версионируется миграциями
- **Docker Compose** — бот, база, pgAdmin и миграции в отдельных контейнерах
- **Деплой на VPS** (Ubuntu), автоматические бэкапы базы в Telegram-канал
- Разработка с февраля 2026 года, один разработчик

## Возможности

**Игровая экономика**
- Гуль: «Щёлк» и «Кофе» (фарм валюты, передоз при злоупотреблении), кагуне
  (4 типа, случайное получение и прокачка), характеристики с экспоненциальной ценой
- Ежедневный бонус: выбор одной из коробок, ~30 видов наград — деньги, сбросы
  кулдаунов, временные эффекты (ускорения, скидки, наценки), редкие улучшения
- Переводы между игроками, рейтинги по каждой механике

**Мини-игры**
- Викторина (лимит в день, история ответов)
- Wordle с рендером игрового поля в картинку
- Лотерея с генерацией видео результата
- `/anime` — нарезка клипов и GIF из серий по таймкодам через ffmpeg

**Групповые чаты**
- Модерация: бан, мут, кик, предупреждения, история действий модераторов, `/report`
- Антиспам (флуд-лимит в памяти) и фильтр ссылок от новых участников
- Приветствия, прощания, правила, пользовательские RP-команды
- AI-собеседник (DeepSeek API), отвечает на реплаи боту
- Развлекательные команды «бот, ...» со случайным выбором участника и вероятностями

**Администрирование**
- Бан в боте, изменение баланса и полей игрока, просмотр профиля, сброс прогресса
- Рассылка, добавление GIF в медиатеку прямо из Telegram (`/add_gif`)
- Уведомления об ошибках администратору с трейсбеком

## Технические решения

- **Слоистая архитектура**: Router → Service → Repository. Сервисы не знают
  про Telegram, репозитории — про бизнес-логику. Подробно — в [ARCHITECTURE.md](ARCHITECTURE.md)
- **Dependency Injection** (`dependency-injector`): зависимости собираются в одном
  контейнере, роутеры получают готовые сервисы
- **Типизированные результаты**: сервисы возвращают dataclass с `ResultStatus`
  вместо исключений и словарей, роутер только отображает результат
- **Кулдауны в БД** с атомарным захватом (`claim`), чтобы двойное нажатие кнопки
  не выдало награду дважды
- **Временные эффекты** хранятся в одном JSONB-поле с временем истечения,
  без отдельной таблицы и фоновых задач
- **Медиатека** на файловой системе с кэшем `file_id` в БД: файл загружается
  в Telegram один раз, дальше отправляется мгновенно
- **Нарезка видео**: асинхронный вызов ffmpeg с семафором и таймаутом,
  чтобы тяжёлые задачи не блокировали бота
- **Middleware** для сквозной логики: сессия БД, синхронизация пользователей
  и чатов, бан, антифлуд, антиспам, счётчик сообщений, логирование
- **Логи по доменам** с ротацией по дням, ошибки дублируются администратору

## Запуск

1. Скопируй `.env.example` в `.env` и заполни переменные.
2. Подними контейнеры:

```bash
docker compose up -d --build
```

Поднимутся бот, PostgreSQL, pgAdmin (`http://localhost:5050`) и сервис миграций.

```bash
docker compose ps            # статус контейнеров
docker compose logs -f bot   # логи бота
docker compose down          # остановить
```

## Конфигурация

| Файл | Что внутри |
|---|---|
| `.env` | токены, доступ к БД, ID администраторов, ключ AI |
| `app/configs/config.yaml` | все тексты бота |
| `app/configs/game.py` | игровой баланс: награды, кулдауны, цены, шансы |
